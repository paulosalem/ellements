

## Contextual information

In any company, results or industry analysis (let's call it the *target*), you must always include as much relevant contextual information as 
possible, to *complement* any specific data about the target being investigated. Such context can include:
  - Where in the economy the target fits:
    * What percentage of relevant financial numbers (e.g., GDP, country exports, country imports)
  - What are the macroeconomic factors currently relevant for the target?
  - What are the political factors currently relevant for the target?
  - What are the relevant competitors or substitutes? What are their relations with the target? Are there risks or
    opportunities?

```json
{
  "queries": [
    "Orders backlogs for upcoming quarters"
  ],
  
  "questions": [
    "Is revenue accelerating or decelerating?"
  ]
}

```

User context information:
```json
{
  "interests": ["Technology", "Computer Science"]
}
```
